# where _ below, on the web

*where _ below*, built for the web to play on an iPad by touch: https://amoniethian.github.io/where-below-triangle/, the whole chain from the title on: the wasteland, the Penrose triangle and the gates' illusions behind its doors, the egg and the board in it, birth, the black room and the ending. Open it in Safari with the iPad held sideways, then choose Share, Add to Home Screen: from there it opens full screen, and once it has loaded it plays without a connection. `?room=3&figure` begins in the Penrose triangle's last room with the figure waiting, and `?gate=5` in a gate's illusion (0 the Rest Gate's to 7 the Open Gate's). This repository holds the exported build only (Godot 4.5, Web, without threads).

《where _ below》的网页版，可以在 iPad 上用触屏玩：https://amoniethian.github.io/where-below-triangle/ ，从标题开始的整条链：荒原、彭罗斯三角和它门后各门的幻境、蛋壳和里面的棋局、出生、黑色房间和结局。在 Safari 里把 iPad 横过来打开，选「分享」，再选「添加到主屏幕」：之后从主屏幕打开就是全屏，加载过一次以后没有网络也能玩。网址后加 `?room=3&figure` 从彭罗斯三角的最后一个房间开始，人形在那里等着；加 `?gate=5` 直接进某一门的幻境（0 是休门，到 7 是开门）。这个仓库里只有导出的成品（Godot 4.5，Web，不带多线程）。
