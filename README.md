# where _ below: the Penrose triangle

The Penrose triangle of *where _ below*, built for the web to play on an iPad by touch: https://amoniethian.github.io/where-below-triangle/. Open it in Safari with the iPad held sideways, then choose Share, Add to Home Screen: from there it opens full screen, and once it has loaded it plays without a connection. `?room=3&figure` begins in the last room with the figure waiting. This repository holds the exported build only (Godot 4.5, Web, without threads).

《where _ below》里的彭罗斯三角，做成网页版，可以在 iPad 上用触屏玩：https://amoniethian.github.io/where-below-triangle/ 。在 Safari 里把 iPad 横过来打开，选「分享」，再选「添加到主屏幕」：之后从主屏幕打开就是全屏，加载过一次以后没有网络也能玩。网址后加 `?room=3&figure` 从最后一个房间开始，人形在那里等着。这个仓库里只有导出的成品（Godot 4.5，Web，不带多线程）。
